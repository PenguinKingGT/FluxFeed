# 10 — UI / UX 重点优化实施计划

## 范围

在不改动 RSS 获取、解析、存储和路由协议的前提下，统一重构 Popup、Reader 与 Settings 的视觉系统和关键交互反馈。

## 实施步骤

1. 审计现有语义色、字体、间距、焦点、加载、空状态和响应式表现。
2. 在 `entrypoints/shared.css` 建立 Quiet Signal 的 Light / Dark 语义 token、基础交互规则和阅读排版。
3. 优化 Popup 的品牌区、Feed 检测、文章列表、空状态和底部操作栏。
4. 优化 Reader 的 Sidebar、搜索/刷新工具栏、文章卡片、阅读标题区、正文与导航。
5. 将 Settings 重组为带分区导航的双列结构，统一设置行、主题选择、数据操作和快捷键表达。
6. 补充或调整 UI 单元测试，覆盖新增的刷新反馈、搜索清除、键盘激活和设置锚点。
7. 执行测试、类型检查、Lint 和生产构建，修复所有本轮引入的问题。

## 不在本轮范围

- 新增后端或同步服务。
- 修改 Feed / Article / Settings 数据结构。
- 新增全文搜索索引或改变搜索算法。
- 改变目录拖拽、删除确认和 OPML 数据语义。
