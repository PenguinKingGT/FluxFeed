# 开源项目文档

## 目标

为 FluxFeed 提供可作为 GitHub 项目入口的正式 README，并让英文、简体中文和日文读者获得同等完整的信息。

## 文档要求

- `README.md` 使用英文，作为默认入口。
- `README.zh-CN.md` 提供简体中文版本。
- `README.ja.md` 提供日文版本。
- 三份文档在顶部互相链接，并保持相同的章节结构。
- 功能、浏览器支持、安装路径、开发命令和 AI 边界必须与当前代码一致。
- 明确说明数据存储、API Key 隔离、AI 请求触发条件和扩展权限原因。
- 提供源码安装、贡献流程、验证命令和核心架构文档入口。
- 不声明尚未存在的商店版本、云同步或 CI 状态；许可证说明必须与根目录 `LICENSE` 一致。

## 维护约定

- 新增或删除用户能力时同步更新三份 README。
- 命令变化以 `package.json` 为准。
- 权限变化以 `wxt.config.ts` 为准。
- AI 隐私和请求策略变化时同步更新 `docs/features/ai-article-summary.md` 与三份 README。
- 当前项目使用 MIT 许可证，三份 README 均链接根目录 `LICENSE`；许可证变化时必须同步更新。
- `AGENTS.md` 必须引用仓库中真实存在的文档和命令，并随测试体系、目录结构、浏览器边界与安全约束变化同步更新。
- 不得在 `AGENTS.md` 中保留已经完成的“未来计划”描述，例如将现有测试目录写成尚未创建。
