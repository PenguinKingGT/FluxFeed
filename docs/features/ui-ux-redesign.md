# UI / UX 重点优化

## 目标

本轮优化不改变 FluxFeed 的数据模型与核心阅读流程，重点解决界面层级弱、状态反馈不足、操作密度失衡和长时间阅读疲劳等问题。设计方向定义为 **Quiet Signal（安静的信号）**：以温和纸张色、深墨色和克制的 RSS 琥珀色构成编辑阅读体验，让用户能快速识别未读信息，同时把注意力留给内容。

## 体验原则

1. **内容优先**：阅读正文、文章标题和来源始终高于容器装饰。
2. **状态清晰**：选中、未读、收藏、刷新、订阅、空数据和加载状态均提供明确反馈。
3. **操作就近**：搜索与刷新保留在文章列表顶部；收藏、已读和打开原文保留在正文上下文内。
4. **键盘可达**：列表项、导航与图标按钮具备可见焦点和正确的可访问名称。
5. **主题一致**：Light / Dark 使用同一套语义色层级，不在组件中散落页面级硬编码颜色。

品牌副标题使用准确的产品类别“订阅阅读器 / Feed Reader / フィードリーダー”，避免“精选资料库”暗示产品会替用户筛选或推荐内容。

## Popup

- 保持 400px 宽、最大 600px 高的扩展弹窗约束。
- 顶部品牌区、检测到的 Feed、未读摘要、文章列表和底部操作形成清晰的五段式结构。
- 文章行整行可点击、可聚焦，未读点只作为辅助信号；来源、时间和标题保持稳定对齐。
- Feed 订阅操作展示进行中、成功和失败状态；Footer 作为轻量操作栏，不与正文列表争夺视觉焦点。

## Reader

- 宽屏保留 Sidebar / Article Panel / Reading Pane 三栏架构，使用色调层级而非大面积阴影分隔区域。
- 阅读布局按可用宽度自动降级：`>= 1440px` 显示完整三栏，`1100px–1439px` 将 Sidebar 收为图标导航轨，`800px–1099px` 将 Sidebar 改为可呼出的覆盖层，`< 800px` 在文章列表与正文之间单页切换。
- 正文工具栏提供专注阅读模式，隐藏导航与文章列表并让正文占满窗口；支持 `F` 快捷键，本地记忆用户选择，无文章时仍保留文章列表。
- 阅读内容统一使用约 860px 的最大宽度，标题、文章信息、正文和媒体保持同一条对齐轴；可用空间不足时继续随阅读栏自适应收窄。
- 中窄宽度的导航覆盖层可由列表或正文工具栏打开，可通过遮罩或 `Escape` 关闭，完成导航后自动收起。
- Sidebar 的当前视图使用低饱和底色、左侧琥珀指示条和清晰字重，不再使用高对比整行黄色。
- Article Panel 增加列表数量语境、可清除搜索、刷新进行中反馈和更清晰的空状态。
- Article Card 优化来源、时间、标题、摘要和标签的扫描顺序；选中态与未读态相互独立。
- Reading Pane 使用更舒适的正文宽度、粘性半透明工具栏、稳定的标题比例和更明确的上一篇/下一篇导航。
- 文章标题字号独立于正文字号设置，并按 Reading Pane 宽度响应：普通布局约 32–44px，专注阅读最大 48px，移动端最大 38px；使用自然换行，避免 `text-wrap: balance` 让中文标题在语义不自然的位置提前断行。
- 移除正文代码块上方与实际内容脱节的空“代码窗口”装饰，直接对真实 `pre` 元素排版。
- 添加订阅弹窗采用紧凑单列节奏：标题、说明、字段和操作区使用一致的内容宽度；目录选择器与 URL 输入框等宽，下拉菜单贴合触发器，不再形成悬空的窄菜单。
- 弹窗 Footer 降低底色对比，保留清晰分隔但不与主要表单争夺视觉注意力。

## Settings

- 页面改为“概览导航 + 设置内容”的双列布局，长页面可快速跳转到 General、Appearance、Data 和 Shortcuts。
- 分区导航使用 `scrollIntoView` 在设置主内容区内滚动，不写入 URL Hash，避免与 Options 页的 `HashRouter` 路由冲突。
- 每个设置分区使用独立但克制的表面层，设置项保持一致的标签、说明和控制器对齐方式。
- 数字、选择、主题卡片、开关和数据操作使用现有 shadcn/Radix 组件语义或等价可访问控件。
- 所有设置仍即时保存，不新增会误导用户的“保存”按钮。
- 外观设置将“配色主题”和“明暗模式”拆分：配色主题提供安静信号、石墨和林间，明暗模式继续提供跟随系统、浅色和深色。
- 安静信号沿用当前 Quiet Signal 的全部浅色与深色 token，并作为新安装和旧设置升级后的默认配色；石墨与林间同样各自提供完整浅色和深色版本。
- 配色主题卡片显示背景、侧栏、正文表面和强调色的真实缩略预览；明暗模式使用紧凑三段式控件，两者均即时保存且独立组合。
- “阅读字号”明确为仅影响文章正文的“正文字号”，使用小 / 标准 / 大三段式选择代替连续 Slider。
- 字号选择区提供与真实阅读器一致的衬线正文样例，切换时即时预览；设置页显示值与阅读器实际值统一为 15 / 17 / 19px。
- 字体偏好拆分为“阅读字体”和“界面字体”：前者只控制文章标题、正文与正文内部标题，后者控制侧栏、文章列表、按钮、弹窗和设置页。
- 阅读字体以用户感知命名为“经典阅读”“简洁现代”和“霞鹜文楷”；界面字体提供“系统默认”和“霞鹜文楷”。不直接展示“衬线 / 无衬线”等字体分类术语，两组设置均通过带真实字形预览的选择卡片即时生效。
- 霞鹜文楷使用随扩展打包的 Lite WebFont 和 Unicode Range 分片，不发起外部字体请求；旧设置自动使用系统无衬线界面与系统衬线阅读字体。
- 霞鹜文楷同时提供 Regular 400 与 Bold 700 字重，界面中的 600 / 700 强调文字不得回退到系统字体；日期、数量和数字输入继续使用界面字体与等宽数字特性，仅代码和快捷键键帽保留等宽字体。
- Popup 与 Options 页面必须显式覆盖 Chrome 注入的 `extension_fonts.css` 字体规则，确保根节点的界面字体偏好能够传递到全部界面组件。

## 视觉系统

- Light：暖白纸张底、浅暖灰表面、深墨文字。
- Dark：深蓝墨背景、略亮表面、柔和浅灰文字。
- Accent：仅使用 RSS 琥珀色表达未读、当前定位和关键订阅动作。
- 每套配色在同一页面内保持完整一致，并仅使用一个主要强调色；所有组件消费语义 token，不直接判断主题 ID。
- 默认 UI 字体采用本地优先的现代人文无衬线栈，默认文章标题与正文采用编辑感衬线栈；用户可分别切换两种字体角色，且不引入外部字体请求。
- 动效控制在 160–240ms，并遵循 `prefers-reduced-motion`。
