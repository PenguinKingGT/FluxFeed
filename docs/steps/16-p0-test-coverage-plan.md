# P0 测试补全计划

## 目标

补齐发布前最关键的自动化测试缺口，重点验证真实扩展运行链路、后台消息边界、浏览器 Runtime 中断恢复和 AI 请求异常。测试必须使用本地夹具，不依赖公网 RSS 或真实 AI 服务。

## 实施范围

### 核心业务 E2E

- 在 Playwright 测试进程启动本地 HTTP RSS 服务。
- 通过真实 Options 页面添加订阅。
- 验证后台 Service Worker 抓取订阅、写入文章并刷新界面。
- 验证打开文章、搜索、收藏、标记已读以及重新加载后的持久化状态。
- 验证删除订阅后目录树和文章列表同步更新。

### 后台消息处理

- 覆盖删除订阅、刷新全部订阅、全部标记已读和收藏文章。
- 覆盖今日简报读取、缓存命中与非法日期。
- 覆盖 AI 凭据状态、更新、输入限制和连接测试错误映射。
- 验证后台依赖抛出异常时返回失败响应，而不是产生未处理拒绝。

### Runtime 中断恢复

- 在统一消息客户端捕获 `runtime.sendMessage` 拒绝。
- 将异常规范化为 `MessageResponse`，确保 Store 能结束加载状态并展示错误。
- 不在各 Store 重复实现相同的 try/catch。

### AI 客户端边界

- 覆盖真实超时触发、网络失败、读取正文时中断。
- 覆盖重定向响应、超大响应体和无 API Key 请求。
- 确保所有失败稳定映射为产品定义的错误码。

## 不在本轮范围

- 覆盖率工具和 CI 工作流。
- 今日简报 Store 的完整状态机测试。
- Firefox 真实浏览器 E2E。
- 使用真实 OpenRouter 或其他公网 AI 服务。
