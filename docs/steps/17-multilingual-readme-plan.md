# 多语言 README 实施计划

## 目标

完成 FluxFeed 面向开源用户和贡献者的英文、简体中文、日文 README，使项目定位、安装使用、隐私边界和贡献流程清晰可查。

## 实施步骤

1. 核对当前功能文档、构建脚本、浏览器产物目录、权限和 AI 数据流。
2. 设计三语一致的 README 信息结构。
3. 使用英文 `README.md` 作为默认入口，新增 `README.zh-CN.md` 和 `README.ja.md`。
4. 加入语言切换、源码安装、开发命令、AI 配置、隐私权限、快捷键、项目结构、贡献和验证章节。
5. 明确项目仍处于发布前阶段，并链接根目录的 MIT 许可证。
6. 检查所有相对链接、GitHub 地址、命令和 Markdown 格式。

## 验收标准

- 三份 README 可以互相切换。
- 三种语言包含相同的核心信息，不存在功能描述冲突。
- Chrome 与 Firefox 的源码安装路径与构建产物一致。
- AI 和本地存储说明符合架构文档。
- 不包含不存在的发布渠道或 CI 徽章，许可证声明与根目录 `LICENSE` 一致。
- `git diff --check` 通过。
