# AI 文章总结与今日简报

## 目标

FluxFeed 使用用户自备的 OpenAI-compatible、Gemini 或 Claude 服务，将当天订阅内容整理为可快速扫描的今日简报，并为单篇文章提供手动或自动总结。用户应能先了解今天发生了什么，再选择值得阅读的文章。

## 用户能力

- 在设置页选择 OpenAI-compatible、Gemini 或 Claude，配置对应地址、模型和 API Key。旧配置缺少 provider 时按 OpenAI-compatible 解释。
- 生成当天全部文章或仅未读文章的今日简报。
- 从简报中的主题和文章摘要直接进入对应文章。
- 在阅读页手动生成单篇摘要。
- 在 AI 设置中控制文章摘要显示，默认显示；隐藏时暂停单篇自动总结，保留缓存和自动总结偏好，不影响手动生成今日简报。旧设置缺少该字段时继续显示。
- 可选择打开文章时自动总结，并设置最小正文字符数。
- 查看缓存摘要并手动重新生成。
- 未配置 AI 时可关闭阅读页的配置提示，关闭选择保存在当前浏览器中，切换文章或重新打开扩展后不再重复显示。

## 实现与兼容性

- AI 偏好按变化字段更新，后台在设置事务内与最新完整配置合并后规范化；不从旧界面快照覆盖其他字段。地址、模型及指令文本框保留输入草稿，避免异步保存或 trim 破坏逐字输入与空格；失焦后显示确认值。API Key 继续使用独立凭据通道。
- 使用 Vercel AI SDK 的 `@ai-sdk/openai-compatible`、`@ai-sdk/google` 和 `@ai-sdk/anthropic`，Gemini 和 Claude 直接使用各自原生协议。
- Gemini 默认基础地址为 `https://generativelanguage.googleapis.com/v1beta`，Claude 为 `https://api.anthropic.com/v1`；留空使用默认值，可覆盖为代理基础地址。兼容服务仍支持基础地址或完整 endpoint。
- 切换供应商重置当前地址和模型；当前只有一套活动配置，API Key 按供应商分别保存，切换不会复用其他供应商的 Key。
- 旧 Key 保留在原存储位置供兼容服务使用；原生供应商不回退读取旧 Key，必须保存自己的 Key。缺少原生 Key 时不发送网络请求。
- 缓存指纹包含供应商，避免相同模型名或地址在不同协议之间误用摘要。
- SDK 仅在后台运行，直接请求用户配置的地址，不引入 Vercel 账号、AI Gateway 或新的权限。
- 关闭 SDK 自动重试与 telemetry，保持分段请求预算；响应在读取时限制为 1 MiB，超大响应立即停止读取。
- 模型结果仍按现有 Zod 规则校验，不强制远端支持 JSON Schema structured outputs，以兼容只实现基础 Chat Completions 的服务。
- 配置、输入校验、缓存、凭据和错误映射集中在 AI module；SDK 的原始错误不会返回页面。
- 单篇及简报的最终汇总均应用语言、长度和自定义要求。

## 请求与费用边界

- 今日简报只在用户点击生成或更新时请求 AI。
- 单篇自动总结默认关闭。开启后，打开符合字符门槛且没有缓存摘要的文章会自动请求 AI。
- Feed 刷新、文章列表渲染和后台 Alarm 不生成摘要。
- 今日简报生成前展示文章数和预计请求次数。
- 批量输入每片最多 20 篇且不超过 24,000 字符，并发不超过 2。
- 单批模型结果格式异常或响应超时时，该批文章使用本地摘要降级并继续处理其余批次。
- 简报遇到认证、限流、网络等终止性错误时停止分派新批次，等待已发出的请求收尾后报告失败；不发起最终汇总、不覆盖旧缓存，不与用户随后重试的遗留请求重叠。
- 外部 AI 请求默认等待最多 120 秒，超时后按分批或最终汇总的对应降级规则处理。
- 最终汇总仅发送文章 ID、简述和主题，并限制输出长度，避免重复发送标题、来源等非必要字段。
- 最终汇总超时或格式异常时，保留已完成的逐篇摘要并生成降级概览，不让成功的分批结果作废。

## 隐私与安全

- API Key 单独保存在 `browser.storage.local`，不进入 Dexie 设置、Zustand、OPML 或 UI 回传数据。
- 外部 AI 请求只从后台 Service Worker 发出。
- API 地址仅允许 HTTP(S)，重定向请求被拒绝。
- 文章内容和模型输出均视为不可信数据。
- 模型输出只按纯文本渲染，不解析 HTML 或 Markdown。
- 模型返回的简报文章 ID 必须存在于本次输入集合，未知 ID 不产生导航。

## 今日简报

- 日期按浏览器本地时区计算。
- 默认范围为当天全部文章，可切换为仅未读。
- 默认最多处理最新 100 篇，可配置为 50、100 或 200。
- 输出包含今日概览、主题和逐篇简述。
- 简报提示词包含明确 JSON 字段协议，解析器可容忍代码块、少量说明文字和超长字段。
- 新文章到达后保留旧简报，并提示更新。
- 完整简报成功后才覆盖旧缓存。

## 单篇总结

- 阅读页按正文内容复用清洗结果；面板隐藏或 AI 未配置时不执行仅供 AI 使用的文本提取、统计与分块。显示且已配置时，自动摘要和手动摘要共享一次计算的结果，正文变化时失效；收藏、已读、请求状态和排版设置变化不重复处理全文。代码高亮保留现有安全清洗和工作量上限。

- 输出包含一段概述和最多 5 条要点。
- 正文保留段落边界；每段最多 30,000 个 UTF-16 代码单元，优先在段落边界切分，无段落时硬切分且不拆开代理对。
- 最多处理 5 段，并发最多 2 个请求；单段直接返回，多段再合并为一段概述和最多 5 条要点，单篇最多 6 次请求。
- 分段和最终合并均应用摘要语言、长度及自定义要求，每次输出限制为 2,000 tokens。
- 超过 5 段的文章跳过自动总结；手动生成或重新生成前必须确认仅处理开头部分，取消不会发起请求。
- 部分摘要持久记录 `isPartial` 和 `chunkCount`，页面持续提示处理范围；旧摘要缺少这两个可选字段时仍可读取。
- UI 到后台的正文消息最多发送前 150,001 个代码单元；额外一个用于保留超限信号，实际处理范围由共享分段规则确定。
- 缓存指纹包含分段策略版本、实际处理的正文和部分处理标记，区分完整摘要与部分摘要。
- 分段或合并失败时保留旧摘要并显示失败；等待当前并发批次结束后返回，不再启动后续批次。多段生成要求有效结构，格式错误不能作为成功结果缓存。
- 自动总结默认关闭，默认门槛为 1,000 个 Unicode 字符。
- 0 表示不设置产品门槛，但正文仍需达到 80 字符硬下限。
- 同一会话自动失败后不重复请求，用户仍可手动重试。
- AI 配置变化不会静默覆盖旧摘要，只提示用户重新生成。

## 第一版不支持

- 后台定时生成简报。
- 流式输出。
- 对话追问、工具调用或跨文章检索。
- 多套 AI 配置。
- 自定义请求头。
- Markdown 或 HTML 结果渲染。

## 自动化测试边界

- AI 客户端使用本地 mock 覆盖超时、网络失败、重定向、超大响应和无凭据请求，不调用真实公网服务。
- 后台消息测试覆盖 AI 凭据状态与更新、连接测试错误映射、今日简报日期校验和缓存读取。
- Runtime 拒绝必须被转换为稳定的失败响应，避免页面出现未处理 Promise rejection。
