# 响应式阅读布局与专注模式实施计划

## 背景

FluxFeed 当前固定展示导航、文章列表和正文三栏。在大显示器上信息密度合理，但在笔记本与窄窗口中，前两栏会持续占用宽度，导致正文行宽过窄、标题换行过多，阅读体验明显下降。

## 目标

1. 根据可用宽度自动调整导航和文章列表，不要求用户理解或维护栏宽。
2. 提供明确的专注阅读模式，让用户可主动隐藏导航与文章列表。
3. 在窄屏中保持收件箱、目录、文章列表和正文均可到达。
4. 保留现有路由、数据加载、键盘导航和文章阅读行为。
5. 布局偏好只保存在本地，不进入 Feed 或文章数据模型。

## 布局规则

| 可用宽度 | 布局 |
| --- | --- |
| `>= 1440px` | 完整导航 + 文章列表 + 正文 |
| `1100px–1439px` | 图标导航轨 + 紧凑文章列表 + 正文 |
| `800px–1099px` | 可呼出的导航覆盖层 + 紧凑文章列表 + 正文 |
| `< 800px` | 可呼出的导航覆盖层；文章列表与正文单页切换 |

专注模式在存在当前文章时隐藏导航和文章列表，使正文占满窗口；退出后恢复先前的阅读上下文。用户选择以版本化的本地偏好保存。

## 实施步骤

1. 为 Reader 根布局、导航、文章列表和正文增加稳定的布局标识与状态属性。
2. 使用 CSS 媒体查询完成四档自动布局，避免监听 `resize` 并触发 React 重渲染。
3. 在中窄宽度加入导航打开入口、遮罩和关闭行为；导航完成跳转后自动收起。
4. 在移动宽度加入“返回文章列表”入口，并根据是否存在当前文章切换列表与正文。
5. 在正文操作栏加入专注模式按钮和提示，同时支持 `F` 快捷键。
6. 使用版本化 `localStorage` 记录专注模式偏好，并对不可用或损坏数据安全降级。
7. 补充中英文与日文文案、单元测试和真实扩展 E2E 检查。

## 验收标准

- 1440px 及以上保持完整三栏。
- 1100px–1439px 导航只保留图标，正文获得更多宽度。
- 800px–1099px 导航默认不占布局宽度，可从列表或正文呼出并关闭。
- 800px 以下选中文章后只显示正文，可返回文章列表。
- 专注模式可通过按钮和 `F` 切换，刷新后保留选择，且无文章时不会让列表消失。
- `pnpm test`、`pnpm compile`、`pnpm lint`、`pnpm build` 通过。
